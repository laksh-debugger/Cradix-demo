# Cradix Demo

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](https://github.com/laksh-debugger/Cradix-demo/pulls)

A demonstration project showcasing the capabilities, integration, and UI component usage of **Cradix**. This repository serves as an interactive sandbox and boilerplate for implementing Radix-based UI components or radix system implementations.

---

## 🚀 Features

- **Component Showcase**: Practical examples of UI primitives and custom radix components.
- **Modern Tech Stack**: Built with high-performance web tooling for instant feedback during development.
- **Responsive Layout**: Ready-to-use template for accessible, mobile-friendly interfaces.
- **Easy Customization**: Cleanly organized structure for rapid experimentation and debugging.

---

## 🛠 Tech Stack

- **Framework**: React / Next.js *(or Vite)*
- **Styling**: Tailwind CSS
- **Primitives**: Radix UI / Custom Components
- **Language**: TypeScript / JavaScript

## 📦 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing.

### Prerequisites

Make sure you have Node.js and a package manager installed:

- [Node.js](https://nodejs.org/) (`v18.0.0` or higher recommended)
- `npm`, `yarn`, or `pnpm`

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/laksh-debugger/Cradix-demo.git
   cd Cradix-demo
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   pnpm install
   # or
   yarn install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   # or
   pnpm dev
   # or
   yarn dev
   ```

4. **Open in Browser**
   Navigate to `http://localhost:3000` (or `http://localhost:5173` if using Vite) to view the project in your browser.
